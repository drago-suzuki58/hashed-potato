# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| potato  | ✅        |

## Reporting a vulnerability

Please report vulnerabilities privately via [GitHub Security Advisories](https://github.com/drago-suzuki58/hashed-potato/security/advisories/new).

See also [`/.well-known/security.txt`](https://3e2e95f5ad970eadfa7e17eaf73da97024aa5359.vercel.app/.well-known/security.txt).

## Known issues

SHA-1 has been considered cryptographically broken since 2017 (SHAttered). A potato with the same SHA-1 hash may exist. We have not found one.
